Why Nova

Nova strips messaging back to what actually matters, then hands you the controls most apps hide.

Stay connected

  • Group messaging for the whole thread, not just one contact

  • Quick greetings for fast replies when you're mid-scroll

Take control

Installation

Sideloading takes two minutes.

Nova ships as an APK on GitHub — no Play Store review, no delay between a fix landing and you having it.

Heads up: some Android builds require enabling Restricted Settings for sideloaded apps. If Nova doesn't open right after install, the steps on the right clear it up in under a minute.

Download the APK

Grab the latest release from GitHub and open it — Android will prompt you to allow the install.

Allow restricted settings

If prompted, tap through Android's restricted settings warning — this is standard for any app installed outside the Play Store.

Open App Info → Storage

Long-press the Nova icon, open App Info, then Storage.

Clear cache, then Force Stop

Tap Clear Cache, then Force Stop. This resolves first-launch issues on most devices.

Reopen Nova

Launch it again — you're set.
